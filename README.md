# 学习空间 · Study Space

一个纯静态的个人知识库：把 Markdown 笔记按「知识模块」放进文件夹，双击启动就能在浏览器里阅读。没有服务端代码，日常使用不需要构建；想发布到公网时，一条命令生成可以上传到阿里云 OSS 等静态托管的站点。

- **一级入口**：首页列出全部知识模块
- **模块内阅读**：左侧目录、右侧本页目录、代码高亮、上一篇 / 下一篇
- **组织方式**：子文件夹即分类，可多层嵌套、可折叠；按名称（自然排序）或时间排序
- **其他**：标题与正文搜索、浅色 / 深色主题、手机适配；新增笔记后刷新即可看到
- **发布**：可构建为不依赖目录列表的静态站点，部署到 OSS、Nginx、GitHub Pages 等

**目录**：[快速上手](#快速上手) · [启动与停止](#启动与停止) · [目录约定](#目录约定) · [排序](#排序) · [发布到公网](#发布到公网阿里云-oss-等静态托管) · [常见问题](#常见问题) · [技术说明](#技术说明)

## 快速上手

1. 双击 `_reader/启动阅读器.bat`，浏览器会自动打开阅读器。
2. 在某个模块文件夹（比如 `fullstack/`）里新建一个 `.md` 文件，文件名带上序号，例如 `03-redis-basics.md`。
3. 文件第一行写 `# 标题`，保存后刷新浏览器，侧栏里就出现了。
4. 想开一个新的学习方向，就在仓库根目录新建一个文件夹，放进笔记，它就是一个新模块。

## 启动与停止

需要本机装有 Python 3（`python --version` 能输出版本号即可）。

| 操作 | 方式（Windows） |
| --- | --- |
| 启动 | 双击 `_reader/启动阅读器.bat`，会自动打开浏览器；已经在运行时只会打开浏览器 |
| 停止 | 双击 `_reader/停止阅读器.bat`，或直接关掉那个最小化的服务窗口 |
| 改端口 | 编辑 `_reader/config.bat` 里的 `set PORT=47321` |

默认地址：<http://localhost:47321/_reader/>

macOS / Linux 在仓库根目录执行，然后打开上面的地址：

```bash
python3 -m http.server 47321 --bind 0.0.0.0
```

> 服务会把整个仓库目录以只读方式公开在这个端口上（`--bind 0.0.0.0` 意味着同一局域网的设备也能访问，方便用手机看）。不需要的话别在路由器上对外网开放这个端口；只想本机访问可以改成 `--bind 127.0.0.1`。

## 目录约定

```
学习空间/
├── fullstack/                     ← 一个知识模块（文件夹名会出现在网址里，建议用英文）
│   ├── _module.json               ← 可选：模块标题、简介、图标、排序
│   ├── 01-xxx.md                  ← 笔记；数字前缀决定阅读顺序，显示时会去掉
│   ├── 02-database/               ← 子文件夹 = 模块内的分类，可以多层嵌套
│   │   ├── _module.json           ← 可选：分类的标题、简介、图标、排序
│   │   ├── 01-mysql/
│   │   │   └── 01-index.md
│   │   └── 02-redis.md
│   └── 03-yyy.md                  ← 笔记和子文件夹按前缀混排：01 → 02 分类 → 03
├── another-topic/                 ← 以后学别的，就再建一个文件夹
├── _reader/                       ← 阅读器本身（见「技术说明」）
└── _dist/                         ← 构建产物，发布到公网时才会生成，不提交到 git
```

- 笔记是 `.md` 或 `.markdown` 文件。标题取自文件里第一个 `# 标题`，没有就用去掉数字前缀的文件名；front matter 里写了 `title` 时以它为准。
- 子文件夹在侧栏和模块页都显示为可折叠的分组；侧栏的折叠状态会记在浏览器里。不含任何笔记的文件夹不会显示。
- 以 `.` 或 `_` 开头的文件和文件夹不会出现在阅读器里，适合放草稿、图片等资源。
- 根目录下的 `.md`（比如本 README）不会被当作笔记。
- 笔记里的图片和链接用相对路径即可，例如 `![](images/er.png)`、`[上一篇](01-xxx.md)`，链接到其他笔记会在阅读器内跳转。

### 排序

侧栏顶部和模块页都有排序开关，选择会记在浏览器里：

| 方式 | 规则 |
| --- | --- |
| 名称（默认） | 有数字前缀的排在前面，按数字大小（`9-` 在 `10-` 前面）；没有前缀的排在后面，按名称自然排序。文件夹的 `_module.json` 里写了 `order` 时以它为准 |
| 最新 / 最早 | 按笔记时间排序，文件夹按其中最新（或最早）的一篇参与排序 |

`上一篇 / 下一篇` 跟随当前的排序方式。

**笔记时间**：优先取 front matter 里的 `date`，没有就用文件的修改时间。文件修改时间在换电脑、重新 clone 后会变，想让时间稳定就在笔记开头写上：

```markdown
---
date: 2026-10-09
---

# 笔记标题
```

### `_module.json`

模块和子文件夹都可以放一个，字段都可选：

```json
{
  "title": "全栈工程师转型",
  "description": "一句话介绍",
  "icon": "🧱",
  "order": 1
}
```

| 字段 | 作用 | 不写时 |
| --- | --- | --- |
| `title` | 显示名称 | 去掉数字前缀的文件夹名 |
| `description` | 显示在首页卡片 / 模块页 / 分组标题下 | 不显示 |
| `icon` | 一个 emoji | 模块用 📚，子文件夹用文件夹图标 |
| `order` | 排序用的数字，越小越靠前 | 取文件夹名的数字前缀，没有就排在最后 |

注意文件要是合法的 JSON（键名加双引号、最后一项后面不能有逗号），否则会被忽略。

## 发布到公网（阿里云 OSS 等静态托管）

本地阅读器靠 Python 静态服务器的「目录列表页」发现笔记。OSS、CDN、GitHub Pages 这类静态托管不提供目录列表，直接上传仓库是用不了的。所以有一个构建步骤，把笔记清单提前生成好：

| 操作 | 方式 |
| --- | --- |
| 生成站点 | 双击 `_reader/构建静态站点.bat`，或在仓库根目录执行 `python _reader/build.py` |
| 输出位置 | 仓库根目录下的 `_dist/`（每次构建会先清空；已加入 `.gitignore`；`_` 开头，本地阅读器不会把它当成模块） |
| 换个输出目录 | `python _reader/build.py --out D:/site`（在仓库内时，最外层文件夹必须以 `_` 开头） |

`_dist/` 里的内容：

```
_dist/
├── index.html            ← 站点首页，自动跳转到 _reader/index.html
├── _reader/              ← 阅读器 + manifest.js（模块、分类、笔记、修改时间的清单）
└── fullstack/ ...        ← 各知识模块原样复制（图片等资源也一起带上）
```

- 阅读器发现页面里有清单就用清单，没有就照旧扫描目录列表，所以**本地双击启动的用法不受影响**。
- 所有路径都是相对的，上传到 Bucket 根目录或任意子目录都能用。
- **每次新增或修改笔记后，要重新构建并上传**，线上才会更新。线上显示的修改时间是构建时文件的修改时间（不是上传时间），写了 front matter `date` 的以 `date` 为准。
- 上线前可以先在本地预览构建结果：`python -m http.server 8000 --directory _dist`，然后打开 <http://localhost:8000/index.html>。

### 在 OSS 上托管

以下是需要注意的设置，具体菜单位置以阿里云控制台当前版本为准：

1. **上传**：把 `_dist/` 里的全部内容（不是 `_dist` 文件夹本身）上传到 Bucket，可以用控制台上传文件夹，或用 `ossutil` 命令行批量上传 / 同步。本地删掉的笔记，Bucket 里也要删掉，同步命令一般有删除远端多余文件的选项。
2. **读写权限**：Bucket 设为「公共读」，或者保持私有、通过 CDN 回源访问。
3. **静态页面**：在 Bucket 的「静态页面」设置里，默认首页填 `index.html`。如果站点放在子目录里，打开「子目录首页」，否则访问 `https://域名/子目录/` 会 404，需要写全 `https://域名/子目录/index.html`。阅读器用 `#/` 路由，不需要配置 404 回退页。
4. **自定义域名**：用 OSS 默认域名直接打开 HTML 会被强制下载而不是显示，所以需要给 Bucket 绑定自己的域名（中国内地地域的域名需要备案），想要 HTTPS 再配置证书。
5. **缓存**：`manifest.js`、`app.js`、`app.css` 的链接带有构建时间作为版本号，重新部署后会自动拿新的；笔记 `.md` 每次都会重新请求。如果前面加了 CDN，记得给 `index.html` 设置不缓存或较短的缓存时间。

> **注意隐私**：上传到公共读的 Bucket 后，所有内容都是公开的，任何拿到链接的人都能看到。`_` 开头的文件和文件夹只是在阅读器里隐藏，**仍会被复制进 `_dist`**（这样笔记引用的图片等资源才能正常显示）。不想发布的内容请放到仓库外，或在上传前从 `_dist` 里删掉。

同样的 `_dist/` 也可以直接放到 Nginx、GitHub Pages、Vercel、Netlify 等任意静态服务器上，规则相同。

## 常见问题

**新建的笔记没有出现？**
先刷新页面。如果还没有：确认扩展名是 `.md`、所在文件夹（包括上级文件夹）不是以 `.` 或 `_` 开头、笔记不在仓库根目录下（根目录的 `.md` 不算笔记）。

**双击启动后浏览器打不开 / 提示端口被占用？**
可能是其他程序占用了这个端口，改 `_reader/config.bat` 里的端口号再启动。如果提示找不到 python，先安装 Python 3，并在安装时勾选「Add Python to PATH」。

**排序不对？**
检查数字前缀后面有没有分隔符（`01-xxx`、`01_xxx`、`01.xxx`、`01 xxx` 都可以，`01xxx` 不算前缀）。子文件夹的 `_module.json` 里写了 `order` 会覆盖文件夹名的前缀。

**线上（OSS）没有更新？**
确认改完笔记后重新运行了构建，并把新的 `_dist` 内容完整上传了。仍是旧内容时，多半是浏览器或 CDN 缓存了 `index.html`，强制刷新或刷新 CDN 缓存。

**线上打开网页变成了下载文件？**
这是 OSS 默认域名的限制，需要绑定自定义域名，见上面第 4 条。

## 技术说明

| 文件 | 作用 |
| --- | --- |
| `_reader/index.html` `app.js` `app.css` | 阅读器本体，纯前端 |
| `_reader/vendor/` | 本地化的依赖：[marked](https://github.com/markedjs/marked)（Markdown 渲染）和 [highlight.js](https://highlightjs.org/)（代码高亮） |
| `_reader/启动阅读器.bat` `停止阅读器.bat` `config.bat` | 本地启动 / 停止 Python 静态服务器 |
| `_reader/build.py` `构建静态站点.bat` | 构建可发布的 `_dist/`，只用 Python 标准库 |

两种运行方式：

- **本地模式**：阅读器读取静态服务器的目录列表页来发现笔记，所以任何会输出目录列表的静态服务器都能用，新增笔记刷新即见。
- **构建模式**：`build.py` 按和阅读器相同的规则扫描仓库，把清单写进 `_dist/_reader/manifest.js`，并在 `_dist` 的 `index.html` 里引入。阅读器检测到 `window.STUDY_SPACE_MANIFEST` 时就不再请求目录列表。

阅读器只读取文件，不会修改仓库里的任何内容。
